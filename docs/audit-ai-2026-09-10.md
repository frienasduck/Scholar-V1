## Measured repair validation — 10 September 2026

- Nine opt-in live adapter tests pass: Groq text (1.27s), checkpoint (0.70s), flashcards (0.59s), planner (0.52s), answer evaluation (1.51s), mock exam (1.62s), streaming (0.58s total, first text 392ms); NVIDIA square (1.55s) and landscape (2.14s). These are short synthetic prompts, not latency promises for large documents.
- Groq configured primary: `openai/gpt-oss-120b`; configured fallback: `openai/gpt-oss-20b`. The successful probes do not prove that provider failover occurred.
- NVIDIA's live endpoint rejected the documentation's cfg_scale 0 with HTTP 422, `greater_than_equal`, `body.cfg_scale`, minimum 1. Existing cfg_scale 1 successfully generated 1024×1024 and 1392×752 images. No image-parameter repair was needed; the timeout was repaired.
- Real local `/api/ocr` with bundled `physics-pt1` page 1 returned 2,008 characters, confidence 81, in 4.72 seconds. This does not test protected Homework Scanner uploads or serverless worker packaging.
- AI Tutor now uses streaming rather than waiting for a whole JSON text response. Browser tests cover rendered/saved answer, controlled provider error, and cancellation with no late saved answer, using synthetic session/provider responses. LAM already streams and now batches UI updates with bounded cancellation.
- Prompt/schema mismatch fixed for mock exams and answer evaluation. Structured token budgets and one shared deadline prevent nested retries from outliving the UI. Slideshow failures now propagate through the shared handler instead of being silently treated as successful fallback AI output.
- Declared quiz requests now reserve/commit/release using the existing ledger. Important remaining limitation: usage tags remain optional in the generic AI API, and slideshow orchestration still checks/counts from the browser. Full non-bypassable capability/quota enforcement needs a server-owned generation workflow and real database concurrency tests. Do not claim quotas fully repaired.
- Remaining live flows: real Free/Plus account round trips; every individual AI tool's complete submit→provider→save→review/export behavior; transcription; protected image/OCR; long slideshow generation/export. Local Prisma configuration is missing `DB_DATABASE_URL` and `DB_DATABASE_URL_UNPOOLED`; local production-mode auth also needs `AUTH_SESSION_SECRET`. No credentials were fabricated or auth guards bypassed.
